# Frigate Android

Приложение для Android, которое показывает камеры и события с сервера видеонаблюдения [Frigate NVR](https://frigate.video).

Это независимый клиент. Он не входит в состав Frigate и не разработан его авторами; для работы нужен собственный сервер Frigate.

## Возможности

- **Live** — сетка камер в реальном времени. Нажмите на камеру, чтобы открыть её крупно, со звуком (если камера его передаёт) и масштабированием жестами.
- **Тревоги сверху** — карусель непросмотренных тревог за последний час. Нажмите на карточку, чтобы открыть запись в архиве.
- **Архив** — просмотр записей камеры с временной шкалой и скоростями 0.5×–16×.
- **Events** — список событий с фильтрами по объектам и зонам.
- **Домашний и внешний адрес** — в Настройках можно указать прямой локальный адрес и домашние сети Wi-Fi (режим просмотра; «Edit» открывает одну форму для основного адреса, домашнего адреса и сетей). Смена основного адреса требует войти заново. Дома приложение работает по локальному адресу, в остальных сетях по основному. Android показывает имя Wi-Fi только при разрешении на геолокацию; без него используется основной адрес.

## Что нужно

- Android 12 или новее.
- Работающий сервер Frigate, доступный с телефона (домашняя сеть, VPN или интернет).
- Учётная запись Frigate с правом просмотра камер.

## Установка

Готовой сборки в магазине приложений пока нет. Собрать из исходников можно так:

1. Установите JDK 21 и Android SDK.
2. В корне проекта выполните `./gradlew assembleDebug`.
3. Установите `app/build/outputs/apk/debug/app-debug.apk` на телефон.

При первом запуске укажите адрес сервера Frigate и войдите под своей учётной записью.

## Frigate NVR

Frigate — бесплатная система видеонаблюдения с открытым кодом. Она записывает камеры и с помощью ИИ находит на видео людей, машины и другие объекты. Документация — на [frigate.video](https://frigate.video), исходный код — в [blakeblackshear/frigate](https://github.com/blakeblackshear/frigate).
